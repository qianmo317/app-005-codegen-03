# ✦ 雅尚美容院管理系统

一款功能完整的美容院管理系统，采用纯前端技术实现，数据通过 Mock.js 生成并使用 LocalStorage 持久化存储。UI 风格简约大气，玫瑰金主题配色，为中小型美容机构提供一站式管理解决方案。

---

## ✨ 功能特性

### 📊 仪表板
- 核心数据概览：本月营业额、新增顾客、预约数量、服务完成数
- 7日营业趋势图（ECharts 折线图）
- 今日预约列表，支持快速状态变更
- 员工业绩排行柱状图
- 会员等级分布统计

### 👥 顾客管理
- **顾客档案**：顾客信息列表，支持姓名/手机号搜索、会员等级筛选
- **皮肤分析记录**：记录每次皮肤检测结果（肤质、油脂、水分、弹性、敏感度），历史对比
- **过敏史管理**：记录过敏源、严重程度、发现日期，支持增删改查
- **消费习惯分析**：ECharts 饼图展示消费偏好分类占比
- **服务历史**：时间线展示所有过往服务记录
- **会员等级**：青铜/白银/黄金/铂金/钻石五级会员体系，积分累计自动升级

### 💆 项目管理
- **美容项目目录**：20+预置美容项目，卡片式展示
- **项目属性**：名称、分类、时长、价格、适用肤质、效果描述
- **分类筛选**：面部护理、眼部护理、身体护理、头发护理、美甲、脱毛
- **肤质筛选**：干性、油性、混合性、中性、敏感肌
- **套餐管理**：多项目组合套餐，优惠价格配置

### 📅 预约排期
- **预约日历**：react-calendar 月视图，日期圆点标记预约数量
- **日视图详情**：按时间顺序展示当日所有预约
- **新增预约**：选择顾客、项目、美容师、日期时间，自动检测时段冲突
- **仪器占用**：预约可指定使用仪器，自动校验仪器可用性与时段占用
- **排队候补**：时段冲突时可加入候补队列
- **状态管理**：待确认/已确认/已完成/已取消/爽约 五种状态
- **预约来源**：电话/微信/到店/线上 四种来源标记

### 🔧 仪器管理
- **仪器台账**：每台仪器记录编号、名称、型号、购进时间、所在房间
- **使用台账**：登记每次使用时长，同一台仪器一天多次使用自动合并计算当日总时长
- **保养提醒**：按累计使用时长或按月份双周期监控，到点自动提醒
- **到期/超期标记**：保养到期（橙色）与保养超期（红色）分开标记，顶栏铃铛同步提醒
- **保养记录**：保养历史跟随每台仪器，支持常规保养/维修，记录费用与经办人
- **状态管控**：在用/保养中/停用三态；停用的仪器不能再被排到项目里
- **占用冲突**：同一台仪器同一时段不能被两个项目同时占用
- **启用限制**：保养未做完的仪器不许重新启用，完成保养后自动重置保养计时

### 👩‍💼 员工排班
- **周排班表**：美容师/技师周视图排班，点击单元格可快速切换班次
- **班次类型**：早班(09:00-14:00)、晚班(14:00-21:00)、全天(09:00-21:00)、休息、加班
- **考勤记录**：今日考勤状态实时展示
- **业绩统计**：按员工统计服务次数、总营收、平均评分
- **客户评价**：顾客评分与评价内容展示
- **技能标签**：美容师擅长项目标签管理

## 🚀 快速开始

### 环境要求
- Node.js >= 16.x
- npm >= 8.x

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后访问 [http://localhost:5173](http://localhost:5173)

### 生产构建

```bash
npm run build
```

### 类型检查

```bash
npm run check
```

### 预览生产构建

```bash
npm run preview
```

## 🎨 设计风格

### 主题配色
- **主色调**：玫瑰金渐变 `#E8C1BA → #D4A0A0 → #C9A86C`
- **背景色**：米白 `#FAFAFA`
- **文字色**：深灰 `#3A3A3A`
- **辅助色**：浅灰 `#F5F5F5`、粉色 `#F8B4B4`

### 设计理念
- 简约大气，大量留白
- 圆角卡片设计，柔和阴影
- 胶囊型按钮，优雅过渡动画
- 响应式布局，支持桌面/平板/移动端

## 💾 数据说明

### 模拟数据
系统首次启动时自动使用 Mock.js 生成以下模拟数据：
- 50+ 顾客记录
- 20+ 美容项目
- 8+ 优惠套餐
- 10+ 员工信息
- 150+ 预约记录
- 200+ 服务记录
- 8 台美容仪器（含到期/超期/保养中/停用演示数据）
- 700+ 仪器使用记录
- 12+ 仪器保养记录
- 14天排班数据
- 80+ 客户评价

### 数据持久化
- 所有数据通过 LocalStorage 自动保存
- 刷新页面数据不会丢失
- 存储键名前缀：`beauty_salon_`
- 可通过浏览器开发者工具清除数据重置
